# ELF Automation

A full-stack legal-tech AI-driven referral and case management platform for automating legal intake, referral generation, attorney network coordination, and communication workflows.

## System Overview
- Secure, scalable legal referral and case management
- AI-driven memo drafting and document review
- Automated referral dispatch and attorney matching
- Human-in-the-loop quality control
- Full case lifecycle tracking
- Role-based dashboards for clients, staff, and attorneys

## Tech Stack
- **Backend:** Node.js (TypeScript), Python (FastAPI), PostgreSQL, Redis, RabbitMQ/Kafka, Elasticsearch, AWS S3
- **Frontend:** React 18+ (TypeScript), Material-UI/Ant Design, Redux Toolkit, React Query, React Native (Expo)
- **DevOps:** Docker, Kubernetes, GitHub Actions, Terraform, Datadog/New Relic, Sentry, ELK Stack

## Directory Structure
```
backend/      # Node.js and Python microservices
frontend/     # React web and mobile apps
infra/        # Terraform, Kubernetes, and deployment scripts
scripts/      # DevOps and migration scripts
docs/         # Architecture and compliance documentation
```

## Development Phases
1. Intake to referral dispatch
